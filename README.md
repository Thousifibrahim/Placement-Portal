# CBSCC

A web-based Placement Management System to streamline college placements. Features student dashboards, company profiles, and email notifications. [Not compatible with mobile] Demo: https://pms.free.nf/

## Overview

This repository contains the source code and supporting files for **CBSCC**.

## Getting started

```bash
git clone https://github.com/Thousifibrahim/CBSCC.git
cd CBSCC
```

Check the repository files for the project-specific entry point and setup requirements. Do not commit credentials, API keys, or private configuration files.
